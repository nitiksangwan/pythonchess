# Placeholder README for assets

Place chess piece images in this folder. Recommended naming:
- wK.png, wQ.png, wR.png, wB.png, wN.png, wP.png (white pieces)
- bK.png, bQ.png, bR.png, bB.png, bN.png, bP.png (black pieces)

Recommended size: 64x64 or 80x80 pixels (to match SQUARE_SIZE in constants.py).

You can find free chess piece images at:
- https://commons.wikimedia.org/wiki/Category:PNG_chess_pieces/Standard_transparent
- https://www.chess.com/terms/chess-pieces

Just download and place the images here.
